# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Arcade Vault: an online platform to play games and compete for the highest score. The project is at an early stage: `app/` is still the Create Next App scaffold (default `page.tsx`, default metadata in `layout.tsx`).

No test runner is configured yet.

## Next.js version caveat

This uses Next.js 16.4.2 / React 19.3 with breaking changes versus what you may know. Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`; start at `index.md`). `AGENTS.md` is auto-regenerated by `next dev`; leave it in place.

`next.config.ts` enables `cacheComponents`, `partialPrefetching` and `experimental.agentFeedback`, so caching/prefetch behavior follows the Cache Components model — check the docs before using the older caching APIs. Tailwind v4 is wired through a Turbopack rule (`@tailwindcss/turbopack`) for `*.css`, with theme tokens declared in `app/globals.css` (`@theme inline`). The `@/*` path alias maps to the repo root. `RootLayout` uses the globally generated `LayoutProps<"/">` type rather than an import.

## Spec-driven workflow

Work follows spec-driven development using the skills from `Klerith/fernando-skills` (locked in `skills-lock.json`, installed in `.agents/skills/` and `.claude/skills/`):

- `/spec <feature>`: interactively designs a spec before any code is written.
- `/spec-impl <NN-spec-name>`: implements an approved spec; requires the spec state to be "Approved", creates a git branch named after the spec, and pauses between steps for diff review.

Both are user-invoked only. Use them for large features instead of coding directly.

## References

`references/templates/` holds a static design prototype (`Arcade Vault.html` plus JSX files: auth, biblioteca/library, detalle/detail, reproductor/player, salon/leaderboard, nav, data, `styles.css`). It is the visual/UX source of truth for screens to be built in `app/`; it is not part of the Next.js build. UI copy in the prototype and README is in Spanish.
